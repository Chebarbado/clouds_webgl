# Модель облакообразования по метеоданным

Цель: из метеорологической обстановки (профиль температуры и влажности, синоптическая ситуация — циклон,
фронты, антициклон, — прогрев подстилающей поверхности) получить **параметры слоёв облачности** в том виде,
который принимает генератор density volume: тип, нижняя граница, мин. толщина, диапазон толщины, окты.
Дополнительно — оценка видимости (туман, осадки) и метеорадарной отражаемости.

Модель диагностическая и «столбовая»: каждый вертикальный столб считается независимо, за доли миллисекунды,
поэтому её можно гонять по сетке (карта циклона) и в реальном времени.

```
 синоптика (p, w, фронты, воздушные массы)   ──►  профиль столба T(z), r(z), w(z)
 прогрев поверхности, время суток            ──►        │
                                                        ├─► частица: LCL, LFC, EL, CAPE, CIN ─► конвективная облачность
                                                        └─► подъём слоёв на Δz = w·τ, RH ─────► слоистая облачность
                                                                                                    │
                       слои генератора (тип, база, толщина, окты) + видимость + dBZ  ◄─────────────┘
```

## 1. Термодинамика

Постоянные: g = 9.81 м/с², R_d = 287.04 Дж/(кг·К), R_v = 461.5, c_p = 1004.6 Дж/(кг·К), L_v = 2.501·10⁶ Дж/кг, ε = R_d/R_v = 0.622.

**Давление насыщения** (Болтон, 1980), T в К:

  e_s(T) = 611.2 · exp( 17.67·(T − 273.15) / (T − 29.65) ) Па

**Насыщающее отношение смеси**: r_s(T, p) = ε·e_s / (p − e_s).
**Относительная влажность**: RH = r / r_s(T, p). **Точка росы** — обращение e_s.

**Виртуальная температура** (для плавучести): T_v = T·(1 + r/ε)/(1 + r).

**Гидростатика**: dp/dz = −p·g / (R_d·T_v) — давление по профилю интегрируется снизу вверх.

**Сухая адиабата**: Γ_d = g/c_p ≈ 9.8 К/км — так охлаждается ненасыщенный воздух при подъёме (и нагревается при опускании).

**Влажная (псевдо)адиабата**: после насыщения выделяется теплота конденсации:

  Γ_m(T, p) = g · (1 + L_v·r_s / (R_d·T)) / (c_p + L_v²·r_s·ε / (R_d·T²))

≈ 4 К/км в тёплом влажном воздухе у земли, → Γ_d в холодном воздухе наверху. Конденсат выпадает (псевдоадиабата).

## 2. Профиль столба

Задаётся параметрами (их же даёт синоптическая модель, раздел 5):

| Параметр | Смысл |
|---|---|
| T₀, Td₀ | температура и точка росы у земли |
| h_BL, Γ_BL | высота и градиент пограничного слоя (днём перемешан — Γ_d; ночью устойчив) |
| ΔT_inv | задерживающий слой (инверсия) на верхней границе ПС, толщина 200 м |
| Γ_ft | градиент свободной атмосферы (6.5 К/км стандарт; 7–8 — неустойчиво) |
| z_trop | тропопауза (выше — изотермия) |
| RH_mid, RH_up | относительная влажность 2–6 км и 6–11 км |
| w, τ | крупномасштабная вертикальная скорость и время её действия |
| ΔT_heat | перегрев приземной частицы (прогрев поверхности солнцем) |

В ПС отношение смеси постоянно (перемешивание) и равно r_s(Td₀, p₀); выше инверсии — по RH.

## 3. Конвекция: метод частицы

Частица стартует у земли с T₀ + ΔT_heat и r₀ и поднимается с шагом 50 м:

1. Сухо-адиабатически, r = const, пока r < r_s(T, p). Высота насыщения — **уровень конденсации (LCL)** = **нижняя граница кучевых**.
   Проверка: формула Эспи z_LCL ≈ 125 м · (T₀ − Td₀).
2. Выше — по Γ_m, r = r_s (конденсат удаляется).
3. Вовлечение (опционально): на каждом шаге частица смешивается с окружающим воздухом, доля ε_e·Δz (ε_e ≈ 0.1–0.2 /км) —
   это ограничивает высоту облаков реалистичнее чистой частицы.

**Плавучесть**: B(z) = g · (T_v,частицы − T_v,среды) / T_v,среды.

- **LFC** (уровень свободной конвекции) — первая высота выше LCL, где B > 0;
- **EL** (уровень равновесия) — последняя высота, где B > 0 — **верхняя граница конвективной облачности**;
- **CAPE** = ∫ B dz (LFC…EL) — энергия неустойчивости, Дж/кг;
- **CIN** = ∫ B dz по участкам B < 0 ниже LFC — задерживающая энергия.

**Запуск конвекции**: |CIN| < 30 + 300·max(w, 0) Дж/кг — прогрев и подъём (фронт, конвергенция) помогают преодолеть задерживающий слой.
Если LFC нет, но частица насыщается внутри перемешанного ПС, получаются «вынужденные» плоские кучевые до инверсии.

**Тип конвективной облачности** по толщине D = EL − LCL и температуре вершины T_top:

| Условие | Тип |
|---|---|
| D < 600 м | Cumulus humilis |
| 600–1800 м | Cumulus mediocris |
| 1.8–3.5 км | Cumulus congestus |
| > 3.5 км, T_top > −20 °C | Towering Cumulus |
| > 5 км, T_top < −20 °C | Cumulonimbus calvus (вершина оледеневает) |
| > 7 км, T_top < −38 °C | Cumulonimbus incus (наковальня у тропопаузы) |

**Покрытие** конвективной облачности (доля σ, окты = round(8σ)):
σ = clamp(0.1 + 0.6·(RH_LCL − 0.6)/0.4 + 0.15·min(CAPE/2000, 1), 0.05, 0.85), где RH_LCL — средняя RH в 500 м под LCL.

## 4. Слоистая облачность: подъём слоёв

Крупномасштабное восходящее движение w за время τ поднимает каждый уровень на Δz = w·τ (при w < 0 — опускание, нагрев, высыхание).
Каждый уровень поднимается как частица (сухо, затем влажно-адиабатически), и на новой высоте считается
относительная влажность RH' и конденсат q_c = max(r − r_s, 0).

**Доля облачности** — схема Сандквиста (Sundqvist, 1989), применяемая в моделях прогноза погоды:

  C = 1 − sqrt( (1 − RH') / (1 − RH_c) ),  RH' ≥ RH_c;  C = 0 иначе

с критической влажностью RH_c(z) = 0.78 + 0.1·exp(−z/1.5 км) (у земли выше — турбулентность и аэрозоль).

Смежные уровни с C > 0.05 (разрывы < 200 м сливаются) образуют **слой**. Классификация:

| Условие | Тип |
|---|---|
| база ≥ 5 км, вершина холоднее −30 °C | Cirrus |
| толщина ≥ 2.5 км, база < 3 км, w > 2 см/с | Nimbostratus |
| база 2–6 км, толщина ≥ 0.8 км | Altostratus |
| база 2–6 км, тонкий или C < 0.7 | Altocumulus |
| база < 2 км, под инверсией, ПС перемешан | Stratocumulus |
| база < 0.5 км, устойчиво | Stratus (база 0 — туман) |

Окты слоя = round(8·C̄), толщина: мин. = 70% наблюдаемой, диапазон = 30%.

## 5. Синоптическая модель (идеализированный циклон)

Плоская область 2000×2000 км, циклон с центром в (x_c, y_c):

- **Давление**: p(r) = p_∞ − Δp·exp(−r²/R²), R ≈ 600 км, Δp ≈ 25 гПа.
- **Ветер**: геострофический, против часовой стрелки (СП), |V| = |∂p/∂r| / (ρ f), f = 10⁻⁴ с⁻¹.
- **Вихрь**: ζ = ∇²p/(ρ f) = 4Δp/(ρ f R²)·(1 − r²/R²)·exp(−r²/R²).
- **Подъём в пограничном слое** (накачка Экмана): w_E = ½·h_E·ζ, h_E ≈ 500 м → несколько см/с в центре, опускание на периферии.

**Фронты** (норвежская схема): тёплый — из центра на восток-юго-восток, холодный — на юго-запад, тёплый сектор между ними.

- **Тёплый фронт**: поверхность раздела с наклоном 1:150. На расстоянии d перед фронтом она на высоте z_f = d/150.
  Тёплый влажный воздух натекает по ней вверх (w ≈ 5–10 см/с): выше z_f RH → 0.9, ниже — холодный сухой воздух.
  Отсюда классическая последовательность при приближении фронта: Ci → (Cs) → As → Ns.
- **Холодный фронт**: крутой (1:50), узкая полоса сильного подъёма (≈ 30 см/с) и неустойчивость → линия Cb.
- **Тёплый сектор**: тёплый влажный воздух у земли (+4 К, Td +5 К) → Cu, Sc, при прогреве — Cb.
- **Тыл циклона** (за холодным фронтом): холодный воздух над тёплой поверхностью, большой градиент, сухо наверху →
  кучевые «открытые ячейки».
- **Периферия / антициклон**: опускание (w < 0) прижимает инверсию → ясно или Sc/St под инверсией.

Для каждой ячейки сетки синоптическая модель задаёт параметры профиля раздела 2, а затем работает столбовая модель.

## 6. Видимость и радар

- **Туман/дымка**: в нижнем слое C > 0.5 → туман; водность LWC = q_c·ρ (г/м³), коэффициент ослабления по Кункелю (1984):
  β = 144.7·LWC^0.88 км⁻¹, V = 3.912/β. Вне тумана — гигроскопический рост аэрозоля: V = V_сух·(1 − RH)^0.5, V_сух ≈ 60 км.
- **Осадки**: Ns или Cb → V ≈ 4–8 км (дождь).
- **Радар**: Cb 40–55 dBZ (по CAPE), Ns 20–30, Cu congestus 10–25; Ci, St, Ac — без эха.
  Это же генератор получает косвенно — через плотность и толщину облаков.

## 7. Связь с генератором

Выход столбовой модели — до 4 непересекающихся слоёв (при пересечении приоритет у конвективной облачности,
слои ниже основания Cu сохраняются), видимость и скорость ветра. Страница демонстрации передаёт их в MVP
параметром `index.html?scene=<base64 JSON>`, и генератор строит облака уже по метеоданным.

## 8. Ограничения и развитие

- Модель диагностическая: облака возникают сразу по состоянию атмосферы, без жизненного цикла (зарождение → зрелость → распад Cb).
  Следующий шаг — прогностическая модель (адвекция влаги, микрофизика, время жизни ячеек).
- Не учитываются орография (подъём над горами, волновые Ac lenticularis) и морской бриз — добавляются как дополнительные w.
- Ветер учитывается только как направление сноса наковальни; сдвиг ветра влияет на организацию конвекции — тоже следующий шаг.
